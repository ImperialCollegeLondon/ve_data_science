# Change log of maliau_2 scenario input data

2026-08-13
- Module: Soil
- Author: Hao Ran Lai
- Files changed:
  - data/scenarios/maliau/maliau_2/data/soil_maliau.nc
- Changes made:
  - Updated the SAFE soil campaign empirical dataset with the following change:
    - The soil clay, silt and sand compositions previously did not sum to 100%,
      these have been normalised so that this is now the case
  - Predictors in the spatial soil model are now log- or log1p-transformed
    because all of them were right-skewed
- References:
  - PR # addressing Issue #489

2026-08-07
- Module: Animal
- Author: Baizurah Malik
- Files changed:
  - Animal functional group input data for the `data/scenarios/maliau/maliau_2`
    scenario.
- Changes made:
  - Revised the Maliau_2 animal functional group input data Level 2 and Level 3.
  - Organised level 1-3 animal input data by increasing levels of ecological
    complexity, from a minimum functional-group setup to progressively broader
    trait and interaction coverage.
  - Updated functional-group representatives using literature-supported adult
    mass, birth mass, diet resources, species-specific data or
    appropriate taxonomic proxies when identified.
  - Standardised the input data format for compatibility with Virtual Ecosystem
    version 0.2.1.
- Notes:
  - Where species-specific trait data are unavailable, appropriate taxonomic
    proxies or published allometric relationships are used and documented in
    the associated input-data records.
