# Change log of maliau_1 scenario input data

- Module: Animal
- Author: Baizurah Malik
- Files changed:
  - Animal functional group input data for the `data/scenarios/maliau/maliau_1`
    scenario.
- Changes made:
  - Revised the Maliau_1 animal functional group input data Level 2 and Level 3.
  - Organised level 1-3 animal input data by increasing levels of ecological
    complexity, from a minimum functional-group setup to progressively broader
    trait and interaction coverage.
  - Updated functional-group representatives using literature-supported adult
    mass, birth mass, diet resources, species-specific data or
    appropriate taxonomic proxies when identified.
  - Standardised the input data format for compatibility with Virtual Ecosystem
    version 0.2.1.
- Notes:
  - Where species-specific trait data are unavailable, appropriate taxonomic
    proxies or published allometric relationships are used and documented in
    the associated input-data records.

- Module: All
- Author: Baizurah Malik
- Files changed:
  - All configuration files in the `data/scenarios/maliau/maliau_1/config`
    folder (Globus)
- Changes made:
  - Replaced the previous scenario configuration files to be compatible with
    Virtual Ecosystem version 0.2.1.
  - soil.microbial_group_definition and soil.enzyme_class_definition have been
    updated to use more realistic values that differentiate the guilds,
    following the same values from the VE example data.
- Notes:
  - Users should verify the file-path entries before running the scenario
    and add the plant output block where required.
  - Added the custom [plants.constants] block, using the scenario-specific values provided in
    data/scenarios
- References:
  - PR #1667 (virtual_ecosystem repo)

2026-07-20
- Module: Abiotic & Hydrology
- Author: Lelavathy
- Files changed:
  - `data/scenarios/maliau/maliau_1/data/era5_maliau_2010_2020_100m.nc` (Globus)
- Changes made:
  - Corrected the conversion of `downward_shortwave_radiation` and
    `downward_longwave_radiation` from J m⁻² to W m⁻² using the correct
    daily time conversion factor (86,400 seconds).
  - Added `diurnal_temperature_range_ref`, calculated as the monthly
    mean of the daily diurnal temperature range derived from ERA5-Land
    hourly 2 m air temperature.

  - PR #414 to close Issue #415
  - PR #417 to close Issue #416
