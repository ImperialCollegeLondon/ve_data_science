# Maliau-2 Tree Standing Carbon Mass

This page brings together the observed-versus-model comparisons and diagnostic
figures for tree standing stem and foliage carbon mass in Maliau-2. The PNGs
remain in their generated locations under `data/derived/`.

## Plot and Grid Coverage

Observed plot footprints are reconstructed as squares using each plot's area.
The figure shows the plot centroids and all VE cells that overlap those
footprints.

![Maliau-2 grid cells and observed plot footprints](../../data/derived/plant/output_data/validation/comparisons/comparisons_figures_maliau_2/maliau_2_cells_and_observed_plots.png)

## Comparison With Observations

Each observed value is shown against the VE cells intersecting its plot. A plot
may overlap multiple cells, so repeated observed values are not independent
observations.

the full grid as the denominator.
All values are in kg C ha-1.
